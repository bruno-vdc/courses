# **Culture and Practices of DataOps and MLOps**

Created for the MLOps lessons at PUC-MG.

This repository contains a complete machine learning project built following good MLOps practices, from development and experimentation to deployment.

### **Highlights**

- End-to-end machine learning pipeline;
- GitHub Actions for CI/CD automation;
- FastAPI for serving machine learning predictions;
- Docker for containerization and cloud deployment;
- Practices focused on reproducibility, automation, and maintainability.
